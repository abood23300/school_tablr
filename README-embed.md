# تضمين "منشئ جدول الدروس" داخل موقعك

يوفّر هذا المشروع صفحة منفصلة `timetable.html` يمكنك نسخها ولصقها داخل أي موقع ويب موجود دون الحاجة إلى تغيير ملف `index.html` لديك.

## الملفات المطلوبة
- `timetable.html` — صفحة التطبيق المستقلة.
- `styles.css` — أنماط الواجهة.
- `js/app.js` — منطق التطبيق والتخزين المحلي.

احرص على الحفاظ على نفس البنية النسبية للمسارات:
```
/your-site/
  timetable.html
  styles.css
  /js/
    app.js
```

إذا كانت بنية ملفات موقعك مختلفة، حدّث مسارات الروابط في أعلى `timetable.html`:
- وسم الأنماط: `<link rel="stylesheet" href="./styles.css" />`
- وسم السكربت: `<script src="./js/app.js"></script>`

## طرق الدمج

1) صفحة خاصة مستقلة:
- انسخ الملفات الثلاثة (`timetable.html`, `styles.css`, `js/app.js`) إلى موقعك.
- افتح الرابط `/timetable.html` مباشرة.

2) تضمين داخل صفحة موجودة (iframe):
- ارفع الملفات كما هي، ثم في صفحتك الرئيسية أضف:
```html
<iframe src="/timetable.html" style="width:100%;height:90vh;border:0;" title="منشئ جدول الدروس"></iframe>
```
- يبقى التطبيق مستقلاً بمخزنه (IndexedDB/LocalStorage) ولا يتداخل مع باقي صفحاتك.

## الملاحظات
- التخزين محليًا في المتصفح (IndexedDB) بحسب النطاق (domain). عند نقل الملفات إلى نطاق جديد، ستبدأ بمشاريع جديدة فارغة افتراضيًا.
- يمكن إعادة تسمية `timetable.html` لأي اسم آخر عند الحاجة مع المحافظة على روابط الملفات.
- للطباعة من العرض المجمّع، تأكد من اختيار وضع الطباعة بالعرض (Landscape). تم تحسين CSS لتكثيف العرض على A4.
- التصدير إلى صورة/Excel/Word يعمل اعتمادًا على الجداول المعروضة حاليًا في تبويب "مشاهدة المنجز".
