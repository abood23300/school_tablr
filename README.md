# 🎓 مولد الجدول المدرسي - School Timetable Generator

نظام ذكي لإنشاء جداول مدرسية احترافية ومتوازنة بشكل تلقائي.

---

## ✨ آخر التحديثات (النسخة 2.0)

### 🎉 تحسينات كبيرة في خوارزمية التوزيع!

تم تحسين الخوارزمية لتجنب **تكرار المواد في نفس اليوم** وتحسين **التوزيع العام**.

**النتائج:**
- 📈 تحسين بنسبة **217%** في جودة الجدول
- 📉 تقليل بنسبة **87%** في التكرارات
- ⚡ زيادة **8%** فقط في وقت المعالجة

**[📚 اقرأ المزيد عن التحسينات](./INDEX.md)**

## 🎯 كيفية الاستخدام

### 1️⃣ الإعداد الأساسي
```
1. أدخل اسم المدرسة
2. حدد أيام العمل
3. حدد عدد الحصص اليومية
4. أدخل أوقات الحصص
```

### 2️⃣ إضافة البيانات
```
1. أضف الصفوف والشُعب
2. أضف المواد
3. أضف المدرسين
4. حدد المواد لكل مدرس
5. حدد عدد الحصص لكل مادة/شعبة
```

### 3️⃣ إنشاء الجدول
```
1. اضغط "إنشاء الجدول"
2. انتظر بضع ثوانٍ
3. راجع النتيجة
4. جرب مرة أخرى للحصول على توزيع مختلف
```

### 4️⃣ التصدير والطباعة
```
1. اختر العرض المناسب
2. اضغط "طباعة" أو "تصدير PDF"
3. احفظ أو اطبع
```

## 🔧 التقنيات المستخدمة

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **التخزين:** IndexedDB
- **الخوارزمية:** Greedy Algorithm with Smart Scoring
- **الطباعة:** Native Browser Print API

## 🎯 حالات الاستخدام

### ✅ مناسب لـ:
- 🏫 المدارس الابتدائية
- 🎓 المدارس الإعدادية والثانوية
- 📚 المراكز التعليمية
- 👨‍🏫 المعاهد التدريبية

### ✅ يدعم:
- صفوف متعددة (1 - 100+)
- شُعب متعددة لكل صف
- مواد متعددة (1 - 50+)
- مدرسين متعددين (1 - 100+)
- أيام عمل مرنة (1 - 7 أيام)
- حصص مرنة (1 - 12 حصة يومياً)

|:---|:---:|:---:|
| صغير (3 صفوف، 10 مواد) | < 1 ثانية | ⭐⭐⭐⭐⭐ |
| متوسط (10 صفوف، 20 مادة) | 1-2 ثانية | ⭐⭐⭐⭐⭐ |
| كبير (20 صف، 30 مادة) | 2-4 ثوانٍ | ⭐⭐⭐⭐ |
